# Wizard Central Toolkit

Focused, reliable command-line tools for developers.

One reliable command is better than one large, unpredictable tool.

Install once, get eleven commands.

## Install

    pip install wiz-central-toolkit

Or from source:

    git clone https://github.com/rewardsbycode-eng/wiz-central-toolkit.git
    cd wiz-central-toolkit
    pip install -e .

Requires Python 3.10+.

## The Tools

| Command       | Purpose                                      |
|---------------|----------------------------------------------|
| pythonwiz     | AST / syntax checks for Python files & trees |
| diffwiz       | Unified file diffs and filtered tree diffs   |
| jsonwiz       | Validate and inspect JSON files              |
| debugwiz      | Traceback autopsy and runtime diagnosis      |
| readwiz       | Read-only policy engine for shell commands   |
| writewiz      | Consent wall for proposed file writes        |
| gitwiz        | Searchable Git manual lookup                 |
| codeguardwiz  | Code integrity scanning and defect detection |
| rustwiz       | Honest Rust validation (cargo check)         |
| todowiz       | Lightweight task storage and queries         |
| bannerwiz     | ASCII banners for terminal headers           |

Every command supports --help.
